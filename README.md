# 🧠 Genius Academy

## Overview

Genius Academy is a modern Flutter learning platform designed to bring multiple educational domains into one application.

The platform currently includes Genius IQ and is designed to expand into parenting, language learning, government examination preparation, school education, general knowledge, and many future learning modules.
